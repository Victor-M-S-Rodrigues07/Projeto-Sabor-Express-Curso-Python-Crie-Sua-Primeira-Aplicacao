## 📝 Descrição do Projeto

A Sabor Express é uma plataforma de cadastro de restaurantes, na qual o usuário pode adicionar a sua loja de comida na lista de restaurantes disponíveis para receber pedidos. Com isso, os usuários podem acessar o perfil da loja e fazer as suas solicitação em um menu dinâmico, simples e fácil de compreender. Com funções bem definidas e mensagens claras para guiar os usuários através da aplicação, o projeto retrata um exemplo comum de aplicativo, com as mesmas práticas, interfaces, propósios e métodos usados no mercado de trabalho da tecnologia. <br>

Cada função do código exerce sua atribuição conferida, garantindo maior modulação, seguindo as boas práticas de programação. Além disso, o código conta com todos os métodos documentados, utilizando a DocStrings do Python. Também nessa aplicação foi aplicado o conceito de dicionários com o objetivo de registrar os dados de forma mais organizada. Por fim, foram criados blocos de repetição com o *for* para iterações com listas e impressões, garantindo otimização e um código mais limpo, seguindo os princípos do *Clear Code*.<br>

Esse projeto foi criado a fim de iniciar o aprendizado da linguagem de programação *Python*, apresentada no curso *Python: Crie a sua primeira aplicação* da Alura (o link do curso estará disponível nos créditos abaixo). <br>
